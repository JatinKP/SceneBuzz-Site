# SceneBuzz

Marketing site for the SceneBuzz Android app.

The HTML pages and `style.css` are generated by `build.py`. Edit the site there, then rebuild:

```bash
python3 build.py
```

Screenshots, the app icon, and the share image live in `images/`. The settings demo (WebM, MP4, and poster) lives in `assets/`. `build.py` copies those files next to the pages.

GitHub Pages serves this repository from the `main` branch root, so `index.html` is the site root. The custom domain is `scenebuzz.389.one`.
